# P1 实现规格：BiDi 下发指纹 JSON → BrowsingContext synced field → C++ 覆盖 navigator.platform

> 目标：管线证明。新增 BiDi 命令下发指纹 JSON → 落成 `BrowsingContext` synced field `FingerprintProfile(nsString)` → C++ 读取点读它覆盖 **navigator.platform**，主 frame + 跨进程 OOPIF 都生效。
> 所有 file:line 对 Firefox **152.0.5** 真实源码（`~/firefox-152.0.5`）。骨架 = 平行复制现有 `PlatformOverride`/`UserAgentOverride` 那条链。

## 0. 数据流（照抄 UserAgentOverride 骨架）
```
BiDi root/emulation.setUserAgentOverride(options)
 └ messageHandler.handleCommand → _configuration._applyConfigurationParameters({category:"user-agent-override", value})
     ├ updateSessionData(...)                       // 存 SessionData，供"未来上下文"重放
     └ #applyConfiguration → #applyConfigurationForCategory("user-agent-override")
         └ setUserAgentOverrideForBrowsingContext({context, value})
             └ context.customUserAgent = value       // WebIDL setter
                 └ BrowsingContext::SetCustomUserAgent → Top()->SetUserAgentOverride(...)  // 写 synced field
                     └ DidSet(IDX_UserAgentOverride): PreOrderWalk 清缓存
新上下文/新进程：_configuration.#onContextAttached 从 SessionData 重放 setXxxForBrowsingContext
读取：Navigator::GetPlatform → bc->Top()->GetPlatformOverride()
```
P1 = 平行复制一份 `FingerprintProfile`，读取点选 `navigator.platform`。

### 1b. `docshell/base/BrowsingContext.cpp`（照抄 3 段，换 IDX）

## 4. navigator.platform 读取点
### 4a. 缓存语义
`dom/webidl/Navigator.webidl` L53-54：`[Pure, Cached, Throws, NeedsCallerType] readonly attribute DOMString platform;`。`Cached` → 改字段后须失效缓存：`DidSet(IDX_FingerprintProfile)`（照抄）→ `ClearCachedPlatform()` → `nsDocShell::ClearCachedPlatform`（nsDocShell.cpp L2308-2319）→ `Navigator::ClearPlatformCache`（Navigator.cpp L2022）→ binding `ClearCachedPlatformValue`。链自动复用，无需新写。

### 4b. `dom/base/Navigator.cpp` WebIDL 版 `GetPlatform`（**L433-456**）插入分支
在 `if (mWindow) {` 里：
```cpp
BrowsingContext* bc = mWindow->GetBrowsingContext();
if (bc) {
  nsString profileJson = bc->Top()->GetFingerprintProfile();
  if (!profileJson.IsEmpty()) {
    nsString platformFromProfile;
    if (ExtractStringKey(profileJson, u"platform"_ns, platformFromProfile) &&
        !platformFromProfile.IsEmpty()) {
      aPlatform = std::move(platformFromProfile); return;
    }
  }
}
```
内部静态版 `GetPlatform(nsAString&, Document*, bool)`（L2031-2062）**不改**（无 BC）。

### 4c. JSON 解析：`JS_ParseJSON`（`#include "js/JSON.h"`）+ `AutoJSAPI`（`#include "mozilla/dom/ScriptSettings.h"`）
```cpp
AutoJSAPI jsapi; if (!jsapi.Init(mWindow)) return false;
JSContext* cx = jsapi.cx();
JS::Rooted<JS::Value> val(cx);
if (!JS_ParseJSON(cx, profileJson.BeginReading(), profileJson.Length(), &val) || !val.isObject()) return false;
JS::Rooted<JSObject*> obj(cx, &val.toObject());
JS::Rooted<JS::Value> pv(cx);
if (!JS_GetProperty(cx, obj, "platform", &pv) || !pv.isString()) return false;
// JS string → nsString: nsAutoJSString.init(cx, pv.toString())
```
样例：`dom/payments/PaymentRequestUtils.cpp:52`、`dom/xhr/XMLHttpRequestMainThread.cpp:705`。

**备选（更简单，无 cx 依赖）**：在写侧 `DidSet(IDX_FingerprintProfile)` 解析 JSON、把 platform 写进 `PlatformOverride` 字段 → 读取点零改动、复用 `GetCustomPlatform`。但 P1「读取点读 JSON」的证明弱一点。**推荐先走 4b+4c 读侧解析**（最直接证明目标）；工程上 P2 起为性能可改为写侧解析缓存。

## 5. 风险 / 注意
- **5a 重编规模**：`BrowsingContext.h` 被 ~139 个 TU include，改 `MOZ_EACH_BC_FIELD` 会大范围重编；但 baseline 首次全量 build 本就编所有东西，不额外增本；只影响之后的增量。BC 字段一次到位以减少反复触发全量。
- **5b OOPIF —— 在顶层 BC 设一次即可，所有子帧(含跨进程 OOPIF)自动生效**：CanSet 强制 `IsTop()` + setter 写 `Top()`，synced field 自动同步到每个持 BC 副本的内容进程；读取走 `bc->Top()->GetFingerprintProfile()`，任意深度/进程子帧解析同一顶层字段。
  - 顶层进程切换（BC 被替换）：`CanonicalBrowsingContext::ReplacedBy`（CanonicalBrowsingContext.cpp L269 起）用 `Transaction txn` 手拷一批字段，UA 在 **L321** `txn.SetUserAgentOverride(...)`（PlatformOverride 此处缺失=Gecko 小遗漏）。**建议 L321 旁补** `txn.SetFingerprintProfile(GetFingerprintProfile());` 保顶层进程切换不丢。
  - 未来 BiDi 新开 top-level：由 2c `#onContextAttached` 从 SessionData 重放补齐。
